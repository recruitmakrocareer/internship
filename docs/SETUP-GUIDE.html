Setup Guide v1.0

คู่มือการติดตั้งระบบ
จัดการนักศึกษาฝึกงาน

ระบบบริหารจัดการนักศึกษาฝึกงานครบวงจร สร้างด้วย Google Apps Script + Google Sheets เป็น Backend และ GitHub Pages เป็น Frontend

ใช้เวลาประมาณ 15-30 นาที ไม่ต้องมีเซิร์ฟเวอร์ ฟรี 100%

สิ่งที่ต้องมีก่อนเริ่มต้น

  • บัญชี Google (Gmail)
  • บัญชี GitHub
  • Fork หรือ Clone โปรเจกต์นี้ไว้ใน GitHub ของคุณแล้ว
1

สร้าง Google Sheets

สร้าง Spreadsheet ที่จะใช้เป็นฐานข้อมูลของระบบ

1.1

เปิด Google Sheets

ไปที่ sheets.google.com แล้วคลิก "Blank spreadsheet" เพื่อสร้าง Spreadsheet ใหม่

1.2

ตั้งชื่อ Spreadsheet

คลิกที่ชื่อ "Untitled spreadsheet" ด้านบนซ้ายมุม แล้วเปลี่ยนชื่อเป็น:

InternshipDB

ไม่ต้องสร้าง Sheet เอง — ระบบจะสร้าง Sheet ทั้งหมด (Users, Assignments, Roadmaps ฯลฯ) ให้อัตโนมัติเมื่อคุณรัน Setup ในขั้นตอนที่ 5

2

สร้าง Google Apps Script

เพิ่มโค้ด Backend ลงใน Apps Script ที่ผูกกับ Spreadsheet

2.1

เปิด Apps Script Editor

จาก Spreadsheet ที่สร้างไว้ คลิกเมนู Extensions > Apps Script

2.2

ลบโค้ดเดิม

ลบโค้ดใน Code.gs ที่มีอยู่เดิมทั้งหมดออก (ฟังก์ชัน myFunction ที่สร้างมาให้)

2.3

สร้างไฟล์ .gs ทั้งหมด

คลิกปุ่ม + ข้างคำว่า "Files" แล้วเลือก Script เพื่อสร้างไฟล์ใหม่ตามรายการด้านล่าง

1 Code.gs Entry point
2 Config.gs Configuration
3 Database.gs CRUD operations
4 Auth.gs Authentication
5 UserService.gs User management
6 RoadmapService.gs Roadmap & progress
7 AssignmentService.gs Assignment & submission
8 EvaluationService.gs Evaluation & scoring
9 ResourceService.gs Learning resources
10 NotificationService.gs Notifications
11 AdminService.gs Admin & setup
12 TrainingPassport.gs Training passport
13 KnowledgeManagement.gs Knowledge sharing
14 FileUpload.gs File upload handling
2.4

คัดลอกโค้ดจาก GitHub

เปิดโฟลเดอร์ apps-script/ ใน GitHub repository แล้วคัดลอกเนื้อหาจากแต่ละไฟล์ไปวางในไฟล์ที่ตรงกันใน Apps Script Editor

เคล็ดลับ: เมื่อสร้างไฟล์ใหม่ใน Apps Script ไม่ต้องพิมพ์นามสกุล .gs ระบบจะเพิ่มให้อัตโนมัติ เช่น พิมพ์แค่ Config ก็จะได้ Config.gs

3

Deploy เป็น Web App

เผยแพร่ Apps Script เป็น Web Application เพื่อให้ Frontend เรียกใช้ได้

3.1

เปิดเมนู Deploy

ใน Apps Script Editor คลิกปุ่ม Deploy > New deployment ที่มุมบนขวา

3.2

ตั้งค่า Deployment

Select type → คลิกไอคอนเฟือง แล้วเลือก Web app
Execute as → Me (อีเมลของคุณ)
Who has access → Anyone
3.3

คัดลอก Web App URL

คลิก Deploy แล้วคัดลอก URL ที่ปรากฏ (จะมีรูปแบบดังนี้):

https://script.google.com/macros/s/AKfycb.../exec

สำคัญ: เก็บ URL นี้ไว้ให้ดี จะต้องใช้ในขั้นตอนถัดไป หากทำ URL หาย สามารถดูได้ที่ Deploy > Manage deployments

4

ตั้งค่า GitHub Pages

เชื่อมต่อ Frontend กับ Backend แล้วเปิดใช้งาน GitHub Pages

4.1

แก้ไขไฟล์ config.js

เปิดไฟล์ docs/js/config.js ใน GitHub repository แล้วแก้ไขดังนี้:

// ตั้งค่า URL ของ Google Apps Script Web App ที่ deploy แล้ว
const API_URL = 'https://script.google.com/macros/s/AKfycb.../exec';

* แทนที่ URL ด้วย URL จริงที่ได้จากขั้นตอนที่ 3

4.2

เปิด GitHub Pages

ตั้งค่าใน GitHub repository ของคุณ:

ไปที่ Repository > Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: /docs
4.3

รอ Deployment

GitHub จะใช้เวลาประมาณ 1-2 นาทีในการ deploy เว็บไซต์ URL จะเป็น:

https://<username>.github.io/<repository>/
5

เริ่มต้นใช้งาน

รัน Setup เพื่อสร้างฐานข้อมูลและข้อมูลตัวอย่าง

5.1

เปิดเว็บไซต์ GitHub Pages

เปิด URL ของ GitHub Pages ที่สร้างไว้ในขั้นตอนที่ 4

5.2

รัน Setup System

กดปุ่ม Setup System บนหน้าเว็บ หรือเรียก API โดยตรง:

YOUR_WEB_APP_URL?action=setupSystem
5.3

ระบบจะสร้างข้อมูลเริ่มต้น

เมื่อรัน Setup สำเร็จ ระบบจะ:

  • สร้าง Sheet ทั้ง 11 รายการ พร้อม Column Headers
  • เพิ่มบัญชีผู้ใช้ตัวอย่าง (Admin, Mentor, Student)
  • เพิ่มข้อมูลตัวอย่าง (Roadmap, Assignments ฯลฯ)
5.4

ล็อกอินเข้าสู่ระบบ

ใช้บัญชีตัวอย่างด้านล่างเพื่อทดสอบระบบ (ดูรายละเอียดในส่วน บัญชีทดสอบ)

เสร็จสิ้น!

ระบบพร้อมใช้งานแล้ว คุณสามารถเริ่มใช้งานระบบจัดการนักศึกษาฝึกงานได้ทันที

Troubleshooting Guide

CORS Error / ไม่สามารถเชื่อมต่อ API ได้

Access to fetch at 'https://script.google.com/...' has been blocked by CORS policy

วิธีแก้ไข:

  • ตรวจสอบว่า Deploy เป็น Web App ด้วยการตั้งค่า "Who has access: Anyone"
  • ตรวจสอบว่า URL ใน config.js ถูกต้อง ไม่มีช่องว่างหรืออักขระเกิน
  • ลอง Deploy ใหม่ (New deployment) แล้วอัปเดต URL ใน config.js
ล็อกอินไม่ได้ / Invalid credentials

วิธีแก้ไข:

  • ตรวจสอบว่าได้รัน Setup System แล้ว (ขั้นตอนที่ 5)
  • ตรวจสอบว่าใช้อีเมลและรหัสผ่านที่ถูกต้อง (ดูส่วน บัญชีทดสอบ)
  • เปิด Google Sheets ตรวจสอบว่า Sheet "Users" มีข้อมูลบัญชีผู้ใช้อยู่
Setup System ทำงานไม่สำเร็จ

วิธีแก้ไข:

  • ตรวจสอบว่าคัดลอกโค้ด .gs ครบทั้ง 14 ไฟล์
  • ลองรัน setupSystem() โดยตรงใน Apps Script Editor (คลิก Run)
  • ตรวจสอบ Execution Log ใน Apps Script (View > Executions) เพื่อดู error
  • ถ้าได้รับ Authorization prompt ให้กด "Review Permissions" > "Allow"
GitHub Pages แสดง 404 Not Found

วิธีแก้ไข:

  • ตรวจสอบว่าเลือก Folder เป็น /docs (ไม่ใช่ / root)
  • รอ 1-2 นาทีหลังจาก enable GitHub Pages (deployment อาจใช้เวลา)
  • ตรวจสอบว่ามีไฟล์ docs/index.html อยู่ใน repository
  • ดูสถานะ deployment ที่ Settings > Pages หรือ tab Actions ของ repository
API ตอบกลับช้า / Timeout

วิธีแก้ไข:

  • Google Apps Script มี cold start ครั้งแรกอาจใช้เวลา 5-10 วินาที ครั้งถัดไปจะเร็วขึ้น
  • ถ้าข้อมูลใน Sheets มีจำนวนมาก อาจช้าลง (แนะนำไม่เกิน 10,000 แถวต่อ Sheet)
  • ตรวจสอบ quota ของ Google Apps Script ที่ script.google.com/home/usageLimits
แก้ไขโค้ดแล้ว แต่ไม่เห็นการเปลี่ยนแปลง

วิธีแก้ไข:

  • Backend (Apps Script): ต้อง Deploy ใหม่ทุกครั้ง (New deployment หรือ Edit deployment)
  • Frontend (GitHub Pages): Push commit ไป GitHub แล้วรอ deployment 1-2 นาที
  • ลอง Hard Refresh หน้าเว็บ (Ctrl + Shift + R)
